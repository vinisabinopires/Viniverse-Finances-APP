1. Local PIN settings
Create local app settings using localStorage.

Settings fields:
- viniverse_pin_enabled: boolean
- viniverse_pin_hash: string
- viniverse_pin_salt: string
- viniverse_lock_timeout_minutes: number
- viniverse_last_unlocked_at: ISO string
- viniverse_privacy_lock_version: string

Use Web Crypto API if available to hash the PIN with SHA-256 plus salt.
Do not store the raw PIN.
Fallback gracefully if Web Crypto is unavailable.

2. Lock screen
Create a LockScreen component.

Behavior:
- If PIN lock is enabled and the app is locked, show a full-screen lock screen before showing financial data.
- The lock screen should match the Viniverse dark glassmorphism style.
- Show app name:
  Viniverse – Finances
- Show a 4-digit PIN input.
- Use mobile-friendly numeric input.
- Add Unlock button.
- Show error message for wrong PIN.
- Do not reveal whether the hash exists or other technical details.
- After successful unlock:
  - store last unlocked timestamp
  - show app normally

3. Setup PIN flow
In More/Settings, add a Privacy & Security section.

Include:
- Enable PIN Lock
- Change PIN
- Disable PIN Lock
- Auto-lock timeout selector:
  - Immediately
  - 1 minute
  - 5 minutes
  - 15 minutes
  - 30 minutes

Setup flow:
- Ask for new 4-digit PIN
- Ask to confirm PIN
- Validate both match
- Save hash + salt
- Enable PIN lock
- Show success feedback

Change PIN flow:
- Require current PIN first
- Then new PIN and confirmation
- Save new hash + salt

Disable PIN flow:
- Require current PIN
- Then disable PIN lock and remove stored hash/salt

4. Lock behavior
The app should lock:
- on initial load if PIN lock is enabled and timeout has expired
- when the user taps a new “Lock App” button in More/Settings
- when the browser/tab becomes hidden and timeout is set to Immediately
- when the app regains focus and timeout has expired

Timeout logic:
- If timeout is Immediately, lock whenever the app becomes hidden and returns.
- Otherwise, compare current time with viniverse_last_unlocked_at.
- If elapsed minutes exceed timeout, lock.

5. Privacy mode while locked
When locked:
- Do not render the main app content behind the lock screen if possible.
- Avoid showing financial amounts, transactions, reports, or account data behind overlays.
- The lock screen should be the only visible UI.
