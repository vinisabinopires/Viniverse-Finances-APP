3. Calendar-style monthly view
Create a mobile-friendly month calendar.

For each day, show compact indicators:
- income total for that day
- expense total for that day
- net amount for that day
- small dots/badges for recurring due items
- visual cue if the day has pending recurring items
- visual cue if the day has generated/recorded transactions

Use simple CSS grid / Tailwind.

The calendar should work well on mobile:
- compact day cells
- readable numbers
- tap-friendly days
- no horizontal overflow

4. Selected day detail panel
When the user taps a day, show a detail panel below the calendar.

Show:
- selected date
- actual transactions for that date
- recurring rules due that date
- pending recurring occurrences
- generated recurring occurrences
- income total
- expense total
- net total

For transactions:
- show description/category/account/amount
- tapping a transaction should open existing transaction detail drawer if easy; otherwise navigate to Transactions with no risky refactor

For recurring occurrences:
- show name, amount, category, account, frequency
- status:
  - Generated
  - Pending
  - Inactive

5. Generate due actions
Add safe generation buttons:
- Generate due transactions for selected day
- Generate due transactions up to today
- Generate due transactions for this month, only up to today

Rules:
- Never generate future transactions.
- Always use existing recurringOccurrenceKey duplicate prevention.
- Show created/skipped result in toast.
- Disable button while generating.
- Running the same action twice must not create duplicates.

6. Bills Timeline section
Below or above the calendar, add a compact “Upcoming Timeline” section.

Show upcoming recurring items for the selected month:
- Today and future days first
- then past pending items if any
- group by date
- show income and expense separately if useful
- show status badge: Pending / Generated / Inactive

This should feel like a simple bills calendar.

7. Monthly cashflow summary
Add compact summary cards:
- Expected recurring income this month
- Expected recurring expenses this month
- Actual income recorded
- Actual expenses recorded
- Pending income
- Pending expenses
- Projected net

Definitions:
- Expected recurring = all active recurring occurrences in selected month and currency
- Actual = generated/normal transactions recorded in selected month and currency
- Pending = recurring occurrences that are due but not generated
- Projected net = expected recurring income - expected recurring expenses plus any non-recurring actual net if simple to calculate

Keep calculations understandable and safe.
If something is ambiguous, label it as estimate.
